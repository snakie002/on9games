# 如果遊戲跟它的劇情一樣，會發生什麼事？

如果遊戲和遊戲敘事一樣，會發生什麼事？落日間轉載、deimos 翻譯的 Nicky Case 文章一開頭就自己回答了：「它們會很屎。」話說得很衝，但點到的彆扭感，不少玩家可能都有過——你在遊戲裡實際做的事，跟遊戲想講的故事，常常根本是兩回事。

## 過場裡的故事，操作裡的另一個遊戲

回想一下很多遊戲的長相：劇情在過場動畫裡演得轟轟烈烈，演完了，拿起手把，又是熟悉的那套跑跳射擊。Nicky Case 在文章裡說，遊戲開發者常參考電影、小說、電視來塑造遊戲故事，結果就是遊戲性與敘事性脫節，「過場動畫—遊戲—過場動畫」成了大多數遊戲的陳舊模式。你多半也遇過這種時刻：角色在劇情裡生死相許，關卡開始後，你只是在清一堆小怪。

問題出在哪？Nicky Case 的觀察是：大多數遊戲其實有一個連續的遊玩空間——操控角色、管理資源、經營世界，玩家隨時都有無數選擇，雖然不見得每個選擇都會開花結果，但選擇的幅度一直都在。可是大多數遊戲故事只給你幾個「分支點」，彷彿劇情只能在特定路口轉彎。

## 分支是一條會爆炸的路

為什麼不乾脆多做一點分支？因為分支會指數爆炸：選項越多，要做的內容越滾越大。Nicky Case 指出，常見的解法也都不怎麼樣——塞一堆死衚衕、把分支重新合併、只在結尾才讓你選，或者把流程做得超短。

所以他提出另一個方向：別執著分支，讓遊戲敘事有一個連續、不斷擴大的可能性空間。玩家的選擇應該「影響」（flavour）之後的故事，而不是開出一條完全獨立的路線。聽起來抽象，但他舉的例子非常具體。

## 《Papers, Please》：當「批准／拒絕」就是玩法

Lucas Pope 製作、3909 發行、2013 年 8 月 8 日上市的《Papers, Please》，玩家在虛構國家 Arstotzka 的 Grestin 邊境檢查站擔任入境檢查官，只靠旅客提供的文件與入境處的原始裝置，決定誰可以入境、誰要被拒絕或逮捕。

Nicky Case 算過一筆帳：每一天你大約要接待十個人，每人一個「批准或拒絕」。如果每個決定都要開一條分支，一天就是 1024 條路線，遊戲總共三十天——當然沒有 1024 的三十次方個結局。實際的做法是讓你的每個小決定去「調味」之後的發展：不小心誤拒了證件齊全的人，故事不會從此改寫，但它會悄悄給你加壓，讓你往後更容易做出不正確、不道德的決定。每天結束時，你還要把當日薪水分配在供暖、食物、家人的醫療上——表面上只是資源管理，實際上卻決定了誰挨餓、誰活下來、誰死去。

更關鍵的是：在《Papers, Please》裡，敘事選擇和遊戲選擇不只操控方式相同，遊戲選擇本身就是敘事選擇。「批准」這個按下去的動作，既是你的工作，也是你的道德表態。行勝於言，玩家控制故事走向的方式，跟玩家操控遊戲的方式，是同一套。

## 一面旗子、幾句閒話，故事就活了

Nicky Case 在文章裡說，他自己最喜歡的時刻是一個「不足掛齒的小選擇」：有人送了他一面 Arstotzka 球隊的旗子，他可以自己決定要不要掛在牆上。跟受賄、拆散家庭、密謀推翻政府這些重大抉擇相比，掛面旗子算什麼？他掛了。而讓他印象深刻的不是掛旗這個動作，是遊戲主動「承認」了它——有人評價這面旗很俗，有人歡呼加油，後來檢查員上門，說掛旗違反規定，還罰了他的錢。

照 Nicky Case 的說法，《Papers, Please》還會透過對話、報紙片段和反覆出現的人物，承認你的其他選擇。當一個遊戲的故事連一面旗都有自己的小弧線，過去的選擇還會回來找你，那種吃驚與困擾，正是「果汁感」的敘事版——與其做一個沉重的大型道德抉擇，不如散佈許多小選擇，讓它們不斷復現。

## 但也有人就是想「選 A 還是選 B」

當然，這個提問不是共識，只是個假設。有一派玩家就是喜歡明確的對話選項：清清楚楚、看得懂、事後還能跟朋友吵「你當時為什麼選那個」。把故事藏進系統裡，對這些人來說等於沒有故事——不是每個人都會從資源分配讀出敘事，機制不會自動變成意義。

Nicky Case 對這種做法的質疑也很直接：為什麼遊戲一要塞劇情選項，操控邏輯就突然從跑動射擊變成「選 A 還是選 B」？他的主張是，玩家影響故事的方式，應該和玩家操控遊戲的方式一致。順帶一提，他在創作半自傳性質的《出櫃模擬器 2014》（Coming Out Simulator 2014）時摸索出這些方法，那款遊戲本身就是把對話與壓力做成系統的一次嘗試。

## 我們覺得

我們覺得，兩派人其實在說同一件事：玩家想被「記得」。大型抉擇誰都會做，真正留下印象的，是遊戲回過頭認得你做過什麼。分支也好、系統也好，如果選擇做完就憑空消失，那故事始終是劇本，不是你的。《Papers, Please》那面旗之所以被記住，不是因為它重要，而是因為它被這個世界回應了——有人喜歡、有人嫌俗、有人來開罰單。

## 那你呢

所以問題還是要丟回給你：如果遊戲真的要像它的劇情一樣活著，你希望它「記得」你做過的哪一類小事？是掛在牆上的那面旗、某個你親手放行的人，還是某筆你省下來的醫藥費？換作是你來設計，你會把故事長在操作裡，還是留在過場裡？
