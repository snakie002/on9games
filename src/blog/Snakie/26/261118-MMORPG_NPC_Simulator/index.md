# 《MMORPG NPC Simulator》2027 年推出：這次不演勇者，開商店、發任務、組團搶寶的 NPC 模擬器

由 Enca Games 開發兼發行的單人模擬 RPG《MMORPG NPC Simulator》，官方宣佈預定 2027 年在 PC（Steam）推出，尚未公開確切日期。這次你演的不是勇者，而是 MMORPG 世界裡站在櫃檯後面的 NPC：經營商店、與「玩家」議價交易、釋出任務、組團下副本打寶。身邊的「玩家」都是模擬出來的，各自有裝備、目標、預算、作息與玩法風格。以下整理本作的遊戲介紹、商店與任務系統、副本團與 Game Master 玩法與發售資訊。

## 遊戲介紹

{% gameImage "header.jpg", "《MMORPG NPC Simulator》官方標題圖", 460, 215, "官方 Steam 商店標題圖：卡通風格的奇幻酒館場景，黃皮膚的獸人店主站在木櫃檯後拿著藥瓶與寶石，左邊的紫皮膚精靈與右邊扛著木桶的綠獸人圍在櫃檯旁，右上角是橘色「MMORPG」與白色「NPC SIMULATOR」字樣。" %}

《MMORPG NPC Simulator》是一款第一人稱的單人遊戲，背景設定在一個模擬運作的 MMORPG 世界，官方標語說得很直接：「這個世界已經不缺英雄了，這次換你當 NPC」。玩家在城鎮裡開一間小店，來來去去的「玩家」會逛商店、接任務、組團出發，而你要在他們的冒險日常裡找出自己的位置。

{% gameImage "screenshot_01.jpg", "城鎮廣場與任務公告板", 1920, 1080, "官方 Steam 遊戲截圖：城鎮廣場上「玩家」聚集在商店與公告板前，角色頭頂顯示名字與等級（如 Lvl 4），商店門口的公告板掛著黃色驚嘆號提示可接取任務，左側有騎著灰馬的玩家經過。" %}

商店從備貨開始：武器、防具、藥水到稀有裝備都要自己補齊。看到便宜貨就殺價買進，用金幣與素材把有潛力的裝備強化後再上架，隨時觀察銷售狀況與顧客反應、調整庫存與定價，把一間小店經營成伺服器裡最重要的地方。

{% gameImage "screenshot_05.jpg", "與「玩家」議價交易", 1920, 1080, "官方 Steam 遊戲截圖：與 20 級玩家 GusNight 的交易介面，對面為 100 組小型生命藥水開價 30,000 金幣，畫面顯示市場參考價、快速報價按鈕與殺價中的交易聊天，對方正在考慮報價。" %}

商店之外，你還能自己決定要發什麼工作、給多少報酬，派「玩家」去蒐集商店需要的素材，驗收他們帶回來的東西，再做成更好的裝備。任務的名稱、型別、目標數量、報酬與掉落分成都由你設定，發布任務本身也要花一筆費用。

{% gameImage "screenshot_06.jpg", "自訂任務的發布介面", 1920, 1080, "官方 Steam 遊戲截圖：QUEST CREATION 介面，任務名稱為 Kill 10 Goblins、型別為 Kill Enemy、目標 10 隻 Zombie，報酬包含 Death Gloves +3、鐵錠與金幣，可選擇任務區域與掉落分配比例，按下 Create Quest 需花費 500 金幣。" %}

等有了裝備和熟客，就能招募懂得各自定位的「玩家」組團出發：幫隊友配裝、準備藥水、談好戰利品分紅、選擇路線，再決定什麼時候該推進、什麼時候該休整。戰鬥中可以透過 Raid Board 隨時掌握隊伍狀態與補給，把打到的稀有掉落帶回商店加工或轉賣。

{% gameImage "screenshot_03.jpg", "Raid Board 與隊伍監控", 1920, 1080, "官方 Steam 遊戲截圖：RAID BOARD 介面顯示前往 Dragon's Lair 的四人隊伍，中央四個即時視窗追蹤各隊員位置，右側隊伍面板列出職業（法師、祭司）、血量、技能列與 WATCH 按鈕，下方是戰鬥紀錄與可拖曳給隊友使用的補給藥水。" %}

## 從店長到 Game Master

經營的成果會累積成名聲，名聲則解鎖 Game Master 權力：到最後你能影響伺服器的裝備、地城掉落、活動與規則，公告你的改動、觀察「玩家」的反應，甚至把搗亂的人封鎖出局。官方的說法是：「商店只是個開始」。

伺服器活動與更新會帶動物價波動，聊天室裡的報價隨時在變，看準行情、用物品加金幣談成一筆好交易，也是每天的功課。

「全服最威嗰個玩家，返到城都要同你買水。」

## 發售資訊與官方宣傳影片

發售資訊整理如下：

- 發售日與平臺：官方宣佈《MMORPG NPC Simulator》預定 2027 年推出，登上 PC（Steam），尚未公開確切日期。
- 開發與發行：由 Enca Games 開發兼發行，Steam 上標示的型別為獨立、RPG、模擬。
- 遊戲模式：單人遊戲，周圍的「玩家」皆為模擬角色；Steam 頁面已開放加入願望清單。
- 配備需求：官方標示最低需求為 64 位元處理器與作業系統、Intel Pentium G3250／AMD FX-8350 等級處理器、4 GB 記憶體、NVIDIA GeForce GTX 650／AMD Radeon HD 7770（1 GB）等級顯示卡與 2 GB 儲存空間。
- 便利與無障礙選項：可調文字大小、鏡頭舒適度、對比控制與音量，支援隨時存檔與字幕選項。
- 角色命名：官方開放在 Discord 投稿想看到的角色名字，有機會被加進遊戲裡成為「玩家」之一。
