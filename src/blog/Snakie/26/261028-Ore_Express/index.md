# 【新作情報】《Ore Express》物理演算工廠自動化：礦石會滾會卡堆成山，出貨全靠大砲與起重機

由 Vj Tenacious 開發、Doble Punch Games 發行的《Ore Express》是一款以物理演算為核心的 2D 工廠自動化沙盒遊戲：玩家要在各種地形挖掘礦石、搭建運輸與加工產線，把貨物送上卡車出貨、賺取資金。遊戲預定 2026 年第四季在 Steam 推出（Windows），商店頁面現已開放加入願望清單，介面語言支援包含繁體中文在內的 11 種語言。

## 遊戲概覽

《Ore Express》的迴圈很單純：挖礦、運輸、加工、出貨。官方形容這是一場「把礦石土石流變成現金」的挑戰——礦石、木料、錠塊與木箱全都是真正的實體物件，會滾動、彈跳、堆疊，把產線堵死，直到你出手修理為止；成百上千的礦塊一路跌跌撞撞，（通常）最後會抵達卡車。沒有任何東西走在預設軌道上，唯一例外是玩家自己鋪的軌道。

{% gameImage "screenshot_02.jpg", "礦石與木料堆積的產線", 1920, 1080, "官方 Steam 遊戲截圖：森林場景中，木料、礦石、金錠與藍色水晶堆成一座小山，藍黃色機械與多條傳送帶圍著礦堆運作，底部輸送帶亮著綠色指示燈。" %}

運輸工具的選擇是本作的核心樂趣。官方列出的「工具箱」包括：傳送帶、木板、斜坡、彈簧墊、風扇、重力升降機、大砲、活塞、電梯、分揀機、電磁鐵、龍門起重機，以及在軌道上行駛的礦車。產線慢了、地形斷了、岩漿擋路？官方的設計哲學就是要玩家無所不用其極——用大砲把礦石直接轟過地形缺口，也是合法手段。

{% gameImage "screenshot_09.jpg", "吊臂把貨物送上卡車", 1920, 1080, "官方 Steam 遊戲截圖：夜間場景，黃色吊臂從高處把紙箱吊放到下方平臺，兩輛卡車在坑底等候裝貨，畫面頂端是正在運作的傳送帶。" %}

加工鏈讓貨物更值錢：窯、熔煉爐、高爐、鑄造廠、工作坊與包裝機，可以把原料一路加工成產品，最後包裝成禮物包裝的貨物再出貨。配合關卡目標——賣出指定數量的礦石、賺到一定金額、建起特定裝置、達成生產效率之類——玩家要在「挖得快」與「運得穩」之間取捨。出貨會換來資金與經驗值，升級與挑戰會給予點數，投入科技樹後可以無上限地研究與強化工具。

{% gameImage "screenshot_13.jpg", "礦車與軌道運輸", 1920, 1080, "官方 Steam 遊戲截圖：礦車行駛在橫跨巖壁的鋼架軌道上，下方草地平臺堆放著機械與黃黑警示配色的裝置，畫面右上角顯示速度控制介面。" %}

關卡為手工打造，分 Easy 與 Hard 兩種難度並附帶挑戰目標；Hard 難度下，卡車沒有訂購的貨物會直接留在坑底堆著。遊戲還有晝夜與天候變化、水與岩漿等地形要素，卡車也會隨著工廠規模一起成長。存檔方面提供 5 個存檔欄位；正式版還會收錄可自由建設的沙盒模式，以及能自建地圖、串聯遊玩的關卡編輯器，Steam 版本亦預定支援成就與 Steam Cloud。

## 體驗版資訊

發行商 Doble Punch Games 已在其官方 itch.io 頁面上架 Web 體驗版《Ore Express Web Demo》，可以直接在瀏覽器試玩：建造傳送帶、大砲與熔爐搬運礦石，再用卡車出貨。不必等正式版，現在就能親手體驗「每個物件都是真的」的產線有多難搞。

## 編輯觀點

物理演算的工廠自動化遊戲不少，但《Ore Express》把「每個物件都是真的」推到極致：產線不會因為你蓋好就乖乖運作，礦石會卡、會堆、會把整條線堵死，玩家的對策也從「最佳化流程」變成「想辦法用大砲、風扇、起重機把問題轟走」。手工關卡加挑戰目標、再配上科技樹與加工鏈，讓它不只是沙盒蓋工廠，而是有明確目標的關卡制體驗。唯一要留意的是目前尚未公佈確切發售日，想先嘗鮮的讀者可以直接玩 Web 體驗版。
