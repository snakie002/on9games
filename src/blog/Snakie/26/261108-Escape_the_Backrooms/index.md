# 四百萬人一起逃離的後室：《Escape the Backrooms》的 co-dev 如何改變玩家體驗

一張詭異的照片在 2019 年被丟上 4chan，七年之後，它長成一個橫跨大型 wiki、病毒影片、甚至大銀幕的共享宇宙——據 Game Developer 的案例專文整理，後室（Backrooms）改編電影還寫下了原創恐怖片史上最佳開畫週末的紀錄。但題材紅，不代表做題材的人雨露均霑：同一篇專文指出，Steam 上標題帶著 Backrooms、且至少收到一篇評論的遊戲超過 270 款，光是 2025 年就有 85 款以上上市。在這種紅海裡，據該文，最後成為最多人探索後室的方式的，卻是一款從學生開發者的 side project 長出來的合作恐怖遊戲《Escape the Backrooms》。

真正值得問的還在後頭：當 Blackbird Interactive 與 Secret Mode 以共同開發（co-dev）的形式加入、把這款個人專案推上四個平臺、累積超過四百萬名玩家之後，這種做法到底給玩家帶來了什麼？它只是把一款小遊戲「做大」，還是改變了我們在後室裡的玩法本身？

## 一張照片長成的紅海，先淘汰的是「只有氛圍」的遊戲

Backrooms 幾乎以一己之力把限界空間（liminal spaces）美學推成主流，據 Game Developer 該文，就連《The Exit 8》這類熱門作品都明顯以它為參照，該作也已推出改編電影。當一種美學變成公共財，氛圍就不再是賣點，而是入場券：黃色桌布、螢光燈、發黴地毯味的無限走廊，任何人都做得出來。

{% gameImage "screenshot_01.jpg", "黃色桌布與螢光燈構成的經典後室迷宮走廊", 1920, 1080, "螢光燈、黃色桌布與走不完的柱廊是後室美學的最低門檻——當所有競品都長得像這張圖，脫穎而出就只能靠設計。" %}

我們認為，在 270 多款同題材遊戲的混戰中，光是「做得像後室」早已不夠。玩家真正在比較的，是誰把這個集體怪談轉化成可以玩的東西。

## 勝出的不是氛圍，是把怪談寫成了規則

翻開 Steam 商店頁的官方介紹，《Escape the Backrooms》的設計幾乎每條都對應到怪談本身的社群規則。後室怪談的生存法則是「不要落單、保持安靜」；遊戲把這兩句話寫成了機制：1 至 4 人合作，採用近距離語音聊天，而且——官方特別提醒——實體也聽得見你說話。

{% gameImage "screenshot_03.jpg", "VHS 錄影帶質感的昏暗房間中，門口站著一個瘦長的黑色人形實體", 1920, 1080, "關卡以 VHS 錄影帶質感呈現實體逼近的瞬間，畫面除了時間戳記幾乎沒有任何 UI——官方所說的「極簡介面」正是為了把恐懼留在場景裡。" %}

從設計角度看，這是一組互相牽動得很漂亮的規則：想救隊友就要出聲，出聲就可能把實體引來；官方同時規定全員必須活著抵達出口才算逃脫（商店頁原文：“No wanderer left behind”），隊友甚至可能 no-clip 到地圖的其他區域。換句話說，「不要落單」不是劇情設定，而是會被系統嚴格執行的規則。實體也不是換皮的追蹤器——官方強調每種實體都有各自的機制，學得快才活得久。恐怖感於是從「跳出來嚇你」轉成「你們這隊的溝通與紀律」。

## 從一個人的 side project，到四個平臺的四百萬人

據 Game Developer 的專文，本作開發者 Fancy 是一位只以化名活動的單人開發者，同時是學生與 YouTube 創作者，得在學業與打工之間擠時間做遊戲。作品像它所改編的怪談一樣滾雪球般膨脹，但也像所有病毒題材一樣，熱潮不等人。

該文的編輯導言把這次合作說得很直接：由經驗豐富的共同開發團隊協助，讓這款單人開發的遊戲「觸及新受眾、解決根本的生產挑戰」。落到玩家手上的成果是具體的：官方標榜 30 多個獨特關卡，並且登上 PC、Xbox、PlayStation 與 Switch 2——據同一篇專文，全平臺累積超過四百萬名玩家。商店頁標示開發商為 Fancy Games 與 Blackbird Interactive、發行商 Secret Mode，上市日期為 2025 年 10 月 23 日。

{% lazyYouTube "6xbnqo48K2c", "Escape the Backrooms - Official Release Trailer" %}

這支由開發者 Fancy 頻道發布的官方發售預告，代表的就是共同開發完成後推向市場的最終版本。我們認為，co-dev 對玩家體驗的影響其實是間接的：它沒有、也無法替 Fancy 想出更好的點子，它補上的是把點子「做完」的能力——30 多個關卡的內容量、四個平臺的移植，這些都不是邊上學邊打工的單人開發者能在熱潮退去前補齊的。玩家得到的不是另一套玩法，而是一個真的被做完、在哪臺主機上都進得去的後室。

## 代價：全隊連坐，以及「必須像後室」的隱形天花板

這套做法有兩筆帳要算。

第一筆是規則的代價。「全員必須活著到出口」把恐怖從個人體驗變成團隊責任：路人隊裡只要一個人失手、或者有人 no-clip 到全隊找不到的地方，所有人就得重頭來過。近距離語音也一樣，它用「不能隨便聊天」換來張力——實體聽得見，等於遊戲對你的麥克風下了噤聲令。反過來說，也正因為這種連坐，四人開黑時才會出現「到底要不要回頭救他」的經典戲劇場面；四百萬名玩家某種程度上證明了，多數人買單的是這種社交恐怖，而不只是被嚇一跳。這是我們的判斷，不是官方說法。

第二筆是熱潮的代價。當 Steam 一年冒出 85 款以上的同題材新作，「做一款後室遊戲」的設計空間其實被社群共識框住了：黃色走廊要對味、VHS 質感要到位、實體要符合 wiki 的想像。co-dev 模式擅長把規格做滿、把平臺鋪齊，但對味的代價就是發明空間變小——你很難在一款乘著熱潮而生的遊戲裡，賭一個玩家不買帳的顛覆性改動。

## 結論：玩家得到的是一個「被做完」的後室

回到開頭的問題：這種 co-dev 做法如何影響玩家體驗？我們的答案是——它改變的不是玩法的核心，而是核心被兌現的程度。近距離語音、全員抵達出口、每種實體各自的機制，這些把怪談寫成規則的巧思屬於 Fancy；30 多個關卡、四個平臺、四百萬人能同時在場，屬於把產能補上的共同開發與發行方。玩家的淨體驗，是從「一個人的病毒式奇觀」變成「一群人的穩定社交恐怖」，代價則是全隊連坐的挫敗感，以及設計上必須對後室美學保持忠誠。

對一款建立在集體想像之上的遊戲來說，「能和朋友一起走進去、而且真的走得出去」，或許才是熱潮退去之後，唯一留得下來的東西。
