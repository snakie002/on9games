# 【新作情報】六發子彈定生死《Six Bullets》正式公開 — 西部劇 CRPG 荒野求生預定 2027 年第三季推出

由 2d6 Software 開發兼發行的《Six Bullets》是一款義大利麵西部片風格的 CRPG：玩家扮演一名連名字都沒有的浪人，在一座火車早已不再停靠的車站小鎮旁醒來，要在無法無天的峽谷荒野裡掙扎求生。遊戲目前僅公佈 PC（Steam）版本，官方標示預定 2027 年第三季推出，確切日期尚未公佈，Steam 商店頁面已經開放。

## 遊戲介紹

{% gameImage "header.jpg", "《Six Bullets》官方標題圖", 460, 215, "官方 Steam 商店標題圖：荒廢西部小鎮的街道上佇立著孤獨人影，長長的陰影延伸成子彈造型，左側是做舊紅色的「SIX BULLETS」標題，右側建築掛著「GENERAL STORE」招牌。" %}

《Six Bullets》是官方形容為「Spaghetti Western」（義大利麵西部片）風格的 CRPG，整個故事圍繞著一個核心限制展開：你的左輪裡，永遠只有六發子彈。你要扮演的是一個沒有名字的浪人，在混亂與絕望裡選擇自己要當怎樣的人。是伸手幫忙，還是處處與人為敵，全看你自己。

{% gameImage "screenshot_01.jpg", "車站小鎮的等距視角", 1920, 1080, "官方 Steam 遊戲截圖：等距俯視視角的荒廢車站小鎮，左側是水塔與鐵路，右側有標著「SALOON」「UNDERTAKER」「HATS」的木造建築，戴寬簷帽的主角站在空地中央，左下角顯示角色肖像與六發左輪彈巢圖示。" %}

小鎮與周遭峽谷就是整場冒險的舞臺。官方在 Steam 頁面上表示，遊戲收錄超過 35 名性格各異的角色，他們的故事彼此交錯——你可以走進他們的人生成為重要的一部分，也可以把他們變成無人提及的註腳。官方也強調 NPC 都記得你做過的每件事，同一段劇情在不同人手上會寫出完全不同的歷史。

{% gameImage "screenshot_02.jpg", "與殯葬業者的對話與技能檢定", 1920, 1080, "官方 Steam 遊戲截圖：木造的殯葬業者工作室內，玩家與灰髮的 UNDERTAKER 對話，右側羊皮紙風格面板顯示敘事文字與對話選項，其中一個選項標註「[Bad Blood - Hard]」的技能檢定難度。" %}

對話系統被官方形容為「荒謬地仔細」：幾乎每個行動、每句選擇的臺詞都有分量。遊戲中的檢定以擲骰進行，而骰面混入的不只是運氣和技能——你在整段旅程中做過的選擇，都會一路影響擲骰的結果。官方也留了一手：就算擲出雙一這種爛骰，說不定反而會開啟一條意想不到的路線。

{% gameImage "screenshot_04.jpg", "八張技能卡牌構成的技能系統", 1920, 1080, "官方 Steam 遊戲截圖：技能選擇介面以八張泛黃卡牌呈現主角的不同技能，包括 Bad Blood、Quickdraw、Wits、Slick、Handy、Silvertongue、Swift、Grit，左下角標示「SKILLS」，背景是荒涼的西部小鎮。" %}

角色養成圍繞著這套卡牌式技能系統展開，技能點全部依照你想走的路線自由分配：可以當個六親不認的狠角色（Bad Blood）、靠一張嘴把人說服得服服貼貼（Silvertongue），或者用一身蠻力解決問題（Grit）。就連穿什麼都有差——帽子、襯衫、靴子的搭配不只改變鎮上居民對你的反應，也會改變你對自己的看法。官方表示每段旅程都會以日誌記錄下來，而你走過的路會決定多重結局的其中一種。

## 玩法特色

依官方 Steam 頁面，遊戲收錄以下內容：

- 超過 35 名不同背景的角色，可互動並決定彼此的旅程
- 服裝自訂：帽子、襯衫、靴子等裝扮會影響他人的反應與自我評價
- 獨特的技能系統，按自己想玩的方式分配技能點
- 極度仔細的對話系統，幾乎每個行動與每句話都有影響
- 探索車站小鎮與周遭峽谷，包含洞穴、流浪者與部族聚落
- 以日誌記錄屬於你自己的旅程
- 互動中的骰子檢定結合運氣、角色技能與玩家一路上的選擇
- 多重結局，取決於你走過的路
- 官方內容標示包含暴力與藥物濫用的描寫

## 編輯觀點

把「彈藥只有六發」做成核心限制的 CRPG 並不多見——官方甚至明說，你可以選擇一發子彈都不打，靠嘴皮子、蠻力或運氣解決事情。骰子檢定會把玩家的選擇一路算進結果裡，加上三十多名會記得你所作所為的角色，如果後續內容撐得起這套設計，每一次遊玩的分量應該都會相當重。當然，遊戲目前仍在開發階段，預定 2027 年第三季才推出，實際內容還是要等官方後續公開為準。
