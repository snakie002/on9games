# 《Toxic Frontier》正式公開

由 Mint Gate Games 開發、Meteorbyte Studios 發行的 **Toxic Frontier** 正式公開，這是一款把卡牌、六角格與生存城市建造結合在一起的 Roguelike 遊戲，目前僅公布 PC（Steam）版本。遊戲已在 Steam 開放商店頁面，官方標示預定於 **2027 年第一季**推出，確切日期尚未公布。

{% gameImage "header.jpg", "Toxic Frontier 主視覺", 460, 215, "Toxic Frontier 官方 Steam 主視覺。" %}

## 遊戲概覽

《Toxic Frontier》是一款以核戰廢土為舞台的 Roguelike 生存城市建造遊戲。玩家從一塊孤零零的六角格地形起步，透過打出手中的卡牌逐步擴張聚落，把受劇毒污染的大地一點一滴淨化回來。由於卡牌是唯一的行動資源，每一步都要想清楚——手牌打完，這一局就結束了。

{% gameImage "screenshot_01.jpg", "Toxic Frontier 遊戲截圖 — 六角格聚落與手牌", 1920, 1080, "官方 Steam 遊戲截圖：被紫色毒霧包圍的六角格聚落，畫面下方為玩家的手牌區。" %}

遊戲的核心玩法是卡牌與六角格地形之間的連動：把卡牌佈署到格子上會觸發連鎖效果，改變整片地形的走向，而每一局都能發掘新的搭配（Synergy）。妥善安排卡牌的落點，荒蕪的廢土就會反過來成為助力；下錯一步，聚落的擴張與淨化進度都會受到拖累。

{% gameImage "screenshot_02.jpg", "Toxic Frontier 遊戲截圖 — 探索者與腐化地形", 1920, 1080, "官方 Steam 遊戲截圖：選中探索者（Explorer）單位的六角格地圖，左側為聚落區、右側為腐化區域。" %}

往廢土深處探索可以解鎖新地形與額外獎勵，但毒霧中也潛伏著威脅。遊戲共有三大生態系，各自擁有獨立的任務、機制與惡劣條件，玩家必須在每一關達成目標分數並擴充牌組。故事背景方面，人類長期躲在地下碉堡避開污染，如今一小群人決定重返地面、對抗腐化、取回失落的世界——而這片「毒地前沿」的力量要如何使用，選擇權在玩家手上。

## 玩法特色

依 Steam 官方頁面，遊戲收錄以下內容：

- 超過 40 張可解鎖、收集的獨特卡牌
- 越來越複雜的地形連動組合待玩家發掘
- 每個生態系都有全新的挑戰與威脅
- 4 種遊戲模式、2 種故事結局
- 支援遊戲手把
- 支援 Steam Deck

## 編輯觀點

把「打牌」與「蓋聚落」綁在同一套系統裡的 Roguelike 近年不算少見，但《Toxic Frontier》讓每一張牌的落點同時影響聚落擴張與淨化進度，加上卡牌用完就結束回合的壓力，決策密度看起來是夠的。40 張以上的卡牌、三大生態系與 4 種模式，如果搭配得當，每一局的變化應該都不會太少。

當然，遊戲目前仍在開發階段，距離 2027 年第一季的預定檔期也還有好一段路要走。「冇牌就收工」這種設計，最怕的就是後期卡牌池撐不起變化——這點就要等之後的試玩資訊來驗證了。
