# 掌機接電視就得忍受撕裂？JSAUX RGB Docking Station 想把 VRR 與 RGB 燈效一起塞進底座

## 這到底是什麼？

JSAUX GAMING 的 RGB Docking Station 是一臺給掌機用的 USB-C 底座：Steam Deck、ROG Ally、Legion Go 這類 USB-C 掌機放上去、接一條線，就能把畫面輸出到電視或螢幕，同時充電、接鍵鼠周邊與網路。官方把它定位成「RGB Gaming Docking Station for Handheld Devices」，分成 8-in-1 與 12-in-1 兩種擴充配置，並以透明外殼加上內建 RGB 燈效，跟一般樸素的底座做出區隔。

## 為什麼玩家會在意

多數掌機底座只解決「能不能輸出畫面」，但接上電視打動作、競速遊戲時，畫面撕裂、卡頓、輸入延遲常常跟著出現。官方宣稱這臺底座採用升級的 HDMI 技術，支援 VRR（可變更新率）、ALLM（自動低延遲模式）與 HDR，並把消除撕裂、卡頓與輸入延遲列為賣點。換句話說，它想把電競螢幕常見的那套顯示規格，搬進掌機的桌面使用情境。對經常把 Steam Deck 或 ROG Ally 接電視玩的玩家來說，這是痛點明確的切入點；RGB 燈效與 OpenRGB 支援則是額外的桌機風格加分項。

## 它怎麼運作

核心概念是「一條 USB-C 進、多種介面出」：掌機接上底座（官方圖示把輸入標為 IN: USB-C HOST），底座負責把影像、資料與電力分流出去。以 12-in-1 版本為例，官方圖示標示的配置包括 HDMI 2.1 與 DisplayPort 1.4 兩個影像輸出（都標示 4K@120Hz）、Gigabit 網路孔、SD 與 TF 讀卡槽、USB-A 3.2 與 USB-C 3.2（10Gbps）、USB-A 2.0、3.5mm 音源孔，以及最高 100W 的 USB-C PD 充電。官方說明影像輸出可做雙螢幕（Windows 支援映象與延伸，macOS 僅映象），但雙螢幕模式的上限是 4K@60Hz 或 2K@120Hz——4K@120Hz 是單一輸出時的標示規格。

燈效部分，官方描述內建呼吸、彩虹波浪、光譜等多種模式，並支援開源的 OpenRGB 軟體調整（官方註明需下載 OpenRGB 0.9），也可以在軟體裡整組關閉 LED。燈效不必依賴專屬軟體，這點對已經在用 OpenRGB 管理桌機燈光的人比較友善。

## 官方說法與已驗證的部分

先講結論：這臺底座目前沒有任何獨立實測可以引用。本文提到的 4K@120Hz 輸出是官方規格標示，VRR／ALLM／HDR 對撕裂、卡頓與輸入延遲的效果是官方宣稱，兩者都屬於廠商說法，不是驗證過的事實；能找到的介紹內容本身也出自官方商店頁面，不構成第三方意見。實際輸入延遲有多少、不同掌機接上去穩不穩定、100W 充電各機型吃不吃得滿，都要等獨立實測出現才能確認。

## 價格、狀態與取得方式

產品目前的狀態是 PREORDER（預購）：官方頁面有下單入口，但沒有任何現貨宣告，出貨時間依官方安排，頁面上也沒有給出確切的出貨日期，實際出貨狀況不明。

價格方面，官方頁面的內文並沒有直接列出售價（下單流程由指令碼產生），官方商品資料則留有 85.99、59.99、45.99 三個價格數字，官方頁面中繼資料的售價欄位標示為 85.99、幣別標示為 USD。哪個數字對應 8-in-1 或 12-in-1 的哪種配置，資料沒有明確寫明，本文也不做任何幣別換算。至於澳洲、臺灣能否直接下單、運費與到貨時間如何，官方完全沒有說明，地區情況不明。

## 適合誰

手上已有 Steam Deck、ROG Ally 或 Legion Go，且經常接電視／大螢幕玩、在意畫面撕裂與輸入延遲的玩家，是這臺產品最直接的目標族群。想用一條線把畫面、充電、網路、周邊全部整合、把掌機當小型桌機用的人也會覺得實用；已經用 OpenRGB 管理整套桌機燈效、不想再多裝一套專屬軟體的人，則是另一個明確族群。

反過來說，純掌機派（從不接大螢幕）用不到它；而習慣給掌機裝保護殼的人，要先注意下面的相容性限制。

## 還有什麼不知道、風險在哪

- 相容性限制：官方唯一的相容性注意事項寫著「RGB docking stations are only compatible with the bare ROG Ally X/Legion Go2/Legion Go S unit」，意思是 ROG Ally X、Legion Go 2、Legion Go S 必須裸機使用，裝上保護殼就不保證相容。至於其他機型的完整支援清單，官方沒有正式列表。
- 4K@120Hz、VRR／ALLM 的實際表現完全未經驗證，規格標示與實測之間往往有落差。
- 雙螢幕上限（4K@60Hz 或 2K@120Hz）出自官方說明，但搭配不同掌機、線材與螢幕時的實際影響仍是未知。
- 85.99 / 59.99 / 45.99 三個價格各對應哪些配置、何時出貨、哪些地區買得到，目前都沒有答案。
- 燈效調整需要自行安裝 OpenRGB 0.9，對不想裝軟體的人是多一個步驟。
