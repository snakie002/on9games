# 【新作情報】《Quadrillion Carrots》12 月 3 日在 Steam 推出 — 徒手拔蘿蔔到榴彈轟田的超規模收割

由 TryMyGames 開發、Own It Interactive 發行的《Quadrillion Carrots》預定 2026 年 12 月 3 日在 Steam 推出。遊戲的核心迴圈很單純：一片巨大農田裡種滿數不清的胡蘿蔔，玩家從徒手一顆一顆拔開始，賺錢換更好的工具、擴充產能，把枯燥的人工一步步升級成官方所說的「收割混沌」。遊戲支援 Windows 與 Linux，目前已在 Steam 開放加入願望清單。

## 遊戲介紹

{% gameImage "header.jpg", "《Quadrillion Carrots》官方標題圖", 460, 215, "官方 Steam 商店標題圖：草地上一隻方形笑臉的輪腳機器人背著滿出來的木箱胡蘿蔔向前跑，沿途胡蘿蔔四處飛散，左側是綠橙配色的 QUADRILLION CARROTS 遊戲標題。" %}

開局玩家兩手空空，只能把胡蘿蔔從土裡拔出來、搬到賣點換錢，再把收入投入工具與升級。官方形容的節奏是「一開始每顆都要花力氣，很快就能幾秒清掉一整區」：乾草耙一次從土裡拉出多顆胡蘿蔔，強力吸塵器直接把作物吸走，榴彈發射器則把爆炸範圍內的胡蘿蔔全部轟出土——每種工具都能強化速度、威力與效率，收割方式越換越狂。

{% gameImage "screenshot_01.jpg", "使用乾草耙收割胡蘿蔔", 1920, 1080, "官方 Steam 遊戲截圖：第一人稱視角手持四齒木柄乾草耙站在農田中，地面與草叢散落大量胡蘿蔔，遠處是木圍籬、樹木與藍天白雲。" %}

工具之外，搬運也是生產線的瓶頸：擴充揹包可以一次搬運越來越誇張數量的胡蘿蔔，揹包升滿後多餘的胡蘿蔔會自動裝箱，不必中斷收割；再啟動搬運機器人把裝好的箱子送往賣點，升級它的移動速度與載量，玩家就能專注清田，讓整套系統自己運轉。

{% gameImage "screenshot_02.jpg", "榴彈發射器把胡蘿蔔轟出土", 1920, 1080, "官方 Steam 遊戲截圖：第一人稱視角手持綠橙色榴彈發射器，畫面左方一團爆炸把胡蘿蔔炸飛到半空中，背景是有樹木與巖壁的農場地形。" %}

地圖方面，遊戲準備了六個大型農田區域，透過中央樞紐互相連結，解鎖順序由玩家自己決定：每區至少清掉一半就能拿到鑰匙，完全清除一區還有永久加成。田裡偶爾會出現會跑的稀有「活體胡蘿蔔」，捕捉後可以解鎖快速移動通道；至於會爆炸的「自爆胡蘿蔔」，就是收割路上的意外驚喜。

{% gameImage "screenshot_03.jpg", "搬運機器人自動運送胡蘿蔔", 1920, 1080, "官方 Steam 遊戲截圖：兩臺小型輪式機器人各拖著一整箱胡蘿蔔的木箱，停在一座淺藍色圓柱設施旁，地面散落胡蘿蔔，遠處是草地、樹木與水岸。" %}

## 編輯觀點

模擬遊戲做到最後，往往就是把「重複勞動」轉化成「生產線」，《Quadrillion Carrots》把這條成長曲線寫得格外直白：徒手拔、耙子拉、吸塵器吸、榴彈轟，接著是自動裝箱與機器人搬運——每一次升級都在把玩家從低效率的農活裡解放出來。六區自由解鎖加上活體胡蘿蔔、自爆胡蘿蔔這些小設計，也讓「清田」這件事不會只是數字堆疊。當然，它賣的就是這種單純而誇張的收割快感，想找一款可以邊放空邊看著數字暴增的休閒模擬，《Quadrillion Carrots》12 月 3 日的上市值得留意。

「一開始用手拔，拔到最後連榴彈發射器都出埋——隻game教你乜嘢叫收割效率，何師傅我種菜都冇咁專業。」
