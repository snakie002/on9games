# 《Garden Souls》免費試玩版現已推出：四位公主×連段取消的 2D 動作 Roguelite

由 Statera Studio 開發、Nuntius Games 與 Vsoo Games 發行的《Garden Souls》是一款以快速戰鬥、華麗連段與流派構築為核心的 2D 動作 Roguelite。免費試玩版《Garden Souls Demo》已於 2026 年 10 月 6 日在 Steam 推出，玩家可以先體驗本作的戰鬥與構築系統。正式版發售日尚未公佈，目前僅支援 Windows 平臺，Steam 商店頁標示支援繁體中文與簡體中文。

## 遊戲簡介

《Garden Souls》的世界被腐化的花卉生態盤踞，玩家要從四位 Garden Princesses 中選擇一位出戰，目標是阻止 Mandragora。四位公主的招式、動畫、技能與連段完全不同：Rose 擅長快速攻擊、高機動與流暢連段；Eris 講求精準、下戳攻擊與空間控制；Solaris 是遠距離彈幕與場面控制的專家；Yuni 則以緩慢、沉重而致命的重擊見長。換一位公主就等於重新學一套打法。

冒險採用程序生成的區域設計，每一輪都會遇上成群敵人、小頭目與頭目；戰鬥之間可以挑選新能力、造訪商店、觸發特殊事件，隨機應變地調整流派。每輪結束後回到據點，可以解鎖永久強化、強化之後的冒險，並一步步發掘這個世界的更多故事。

## 戰鬥與構築系統

《Garden Souls》的戰鬥走快速、技術取向的路線，官方形容這套系統獎勵創意：地面與空中攻擊可以互相銜接，用衝刺、跳躍或法術取消招式就能延長連段，甚至把敵人長時間留在空中，直到打出理想的起手式。移動方面有衝刺、二段跳與蹬牆跳；戰術上可以破壞敵人防禦、把對手打飛撞牆，掌握整場戰鬥的節奏。

流派構築則圍繞「Extra Strikes（額外招式）」「Elements（元素）」「Spells（法術）」「Bombogs」「Strikers」與「Artifacts」展開：每一輪解鎖新招式、以元素為打擊附加特殊效果、用法術扭轉策略；Bombogs 是會自動作戰的花朵夥伴，Strikers 是能延續連段或逆轉戰局的召喚夥伴，Artifacts 則負責強化整個構築。攻擊還能注入六種元素之力，配合招式組合出屬於自己的戰鬥風格。

值得一提的是，開發商 Statera Studio 過往作品包括以 90 年代經典格鬥遊戲為靈感的《Pocket Bravery》；本作把連段、取消、破防這套格鬥遊戲常見的動作語彙搬進 Roguelite 的框架裡，手感取向相當明確。
