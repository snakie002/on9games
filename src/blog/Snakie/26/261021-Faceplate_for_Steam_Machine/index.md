# Steam Machine 的面板可以直接變螢幕？JSAUX 磁吸 Faceplate 的兩種玩法

## 這是什麼東西

JSAUX GAMING 的「Faceplate for Steam Machine」是一塊磁吸式前面板，專門裝在 Steam Machine 機身正面：把主機前方的面板換成一塊小螢幕。官方對這個概念的描述是「Give Your Steam Machine a New Front」，也就是讓主機正面變成一塊配合你桌面配置的顯示器。

官方規格寫著兩種面板可以選：

- **5.83 吋 E-Ink 面板**：走藍芽連線，黑白顯示，內建 500mAh 電池。官方標示它在顯示靜態內容時耗電接近零、續航最長可達 22 天，定位是低耗電、常亮的資訊顯示。
- **7 吋 Pixel Matrix 面板**：走 USB-C 連線、持續供電，主打彩色畫素圖、動態 GIF 與即時系統狀態更新。

兩款走的是不同取向：一個求安靜、免插電、常亮；一個求色彩與即時動態。

## 為什麼玩家會在意

Steam Machine 這種方形主機放在桌上，正面本來是一塊「什麼都不做」的空間。這款產品的思路很直接：把那塊空間用起來，變成顯示資訊或個人風格的螢幕，而且不佔用額外桌面空間（官方如此描述）。

對玩家來說，真正有感的點有兩個。第一是資訊疊加：官方產品圖展示的「Composite」版面把 GPU、CPU、RAM 使用率、FPS，還有正在玩的遊戲與遊玩時間一起放在主機正面；圖上的標語寫著「Six Modes. One Display.」，示範的預設版面包括 Performance、Weather、Clock、Game Time、Calendar。第二是個性化：官方宣稱兩種面板都能透過 App 上傳自訂圖片，Pixel Matrix 面板還支援 GIF 與開源程式碼自訂多區版面，給開發者留了後門。

## 它怎麼運作

安裝方式是磁吸。官方宣稱面板可以直接吸附在 Steam Machine 前方，不需要螺絲或卡扣，裝上後與機身融為一體。連線與供電則依面板版本不同：E-Ink 版走藍芽、靠內建電池運作；Pixel Matrix 版走 USB-C、由主機持續供電，因此能做到即時更新。

顯示內容由隨附的 App 控制，官方表示可以選預設顯示模式，或上傳自己的圖片。不過官方也提醒了一句：App 介面與可用的顯示模式可能會有所不同，現在看到的版面不保證就是最終樣子。

{% gameImage "p01_pm0106-steam-machine-faceplate-2-9457076.jpg", "官方圖示範磁吸安裝：手持面板貼向 Steam Machine 前方", 1920, 1080, "官方安裝示意圖用綠色圓點標出磁吸位置，圖上文字寫著「Snap On. Power Up.」與「Magnetic installation with no screws or clips」。" %}

官方還有一條實務提醒值得注意：因為 Steam Machine 的埠保護機制，Pixel Matrix 面板要避免使用大面積白色的圖片——所有畫素同時點亮可能讓面板過載、影響正常運作。換句話說，這塊彩色面板不是「想放什麼就放什麼」。

## 哪些是官方說法，哪些真的查證過

先講結論：目前這批資料裡，所有規格數字都來自 JSAUX 官方頁面，屬於廠商標示，沒有任何獨立實測可以佐證。

官方說法（未經獨立驗證）包括：5.83 吋與 7 吋的面板尺寸、500mAh 電池、最長 22 天續航、藍芽與 USB-C 連線、官方圖上標語寫著的六種顯示模式、App 上傳自訂圖、Pixel Matrix 支援開源多區版面。這些都只能寫成「官方規格寫著」。

可以確認的事實比較少但很具體：官方產品頁確實存在，並且有下單入口；官方頁面寫著「Faceplate for Steam Machine in stock.」，也就是官方表示現貨供應。至於吸附穩不穩、螢幕素質如何、22 天續航是不是真的，目前都沒有獨立證據可引用——ON9 也沒有實測過這款產品。

最直接的目標族群是已經有 Steam Machine 的人——官方對相容性的全部說明就是「為 Steam Machine 設計」這件事本身，產品名與說明都寫著 Made for Steam Machine，但沒有任何正式的相容性宣告，也沒提到其他裝置。

再細一點看：喜歡桌搭、想讓主機正面有點動靜的人，會被 Pixel Matrix 的彩色畫素圖與 GIF 吸引；只想低調顯示天氣、時間、日曆，而且不想多拉一條線的人，E-Ink 版本的免插電常亮比較符合需求（官方宣稱靜態內容續航最長 22 天）；會寫程式、想自己排版面的人，官方說 Pixel Matrix 支援開源程式碼做多區版面。

## 還不知道的事與風險

整理一下目前的空白地帶：

- **沒有獨立實測。** 續航、磁吸力、螢幕觀看角度、App 完成度，全部只有官方說法，本文也沒有任何第一手使用經驗。
- **價格對應不明。** 99.99 與 89.99 兩個數字各對應哪種規格，官方證據沒有寫；官方頁面可見內容也沒有直接的售價標示。
- **供貨地區不明。** 官方沒有說明出貨地區，臺灣與澳洲讀者能否直接下單、要負擔多少運費與稅，都要自己確認。
- **Pixel Matrix 有使用限制。** 官方提醒避免大面積白色圖片，否則可能讓面板過載、影響運作。
- **AI Agent 選用功能的隱私成本。** 官方說明寫著：這個選用功能啟用後，外掛會讀取本機的 Codex 登入憑證、存取 ChatGPT/OpenAI 服務以取得使用額度與最近工作階段資訊；官方自己也提醒要確認安裝來源、並瞭解隱私與 token 安全風險。要不要啟用，值得先想清楚。
- **顯示模式可能變動。** 官方寫著 App 介面與可用顯示模式可能會有所不同。

總結來說，Faceplate for Steam Machine 是個思路清楚的產品：把主機正面這塊閒置空間變成可自訂的顯示器，並且給出「免插電常亮」與「彩色即時」兩條路線。概念不複雜，但下手前要認清：目前能查證的只有官方說法與官方頁面的供貨狀態，實際表現如何，要等更多獨立測試出現才有答案。
