# 《狂熱運輸3》讓貨物「先動再說」：13 年運輸系列在解決什麼問題？

運輸模擬遊戲最有趣的時刻往往是開局：看地形、畫路線、算運量。問題是網路一旦成形，剩下的就只是等收益報表。如果續作只會把地圖做得更大、車輛做得更多，它很容易淪為前作的資料片。《狂熱運輸3》（Transport Fever 3，Steam 的中文介紹稱它為《運輸業大亨3》）是瑞士獨立團隊 Urban Games 做到第 13 年的作品，但 TGS 2026 期間觸樂對團隊資深 3D 美術 Manu Oehler 的專訪裡，談到的改動幾乎都圍繞同一件事：決策應該發生在什麼時候。我們認為，這一代真正的課題不是「加什麼」，而是「把玩家的決定從開局搬到全程」。以下就用專訪中的具體例子，拆解這些取捨背後究竟在解決什麼問題。

## 為什麼是「第 13 年」的問題

據觸樂報導，Urban Games 是 2013 年成立於瑞士的獨立工作室，從《Train Fever》開始就一直圍繞鐵路、城市與運輸網路做遊戲。系列的核心迴圈十多年沒變：鋪開公路、鐵路與航線，把原料、貨物與乘客送到需要的地方，再用賺來的錢擴張網路，在超過 125 年的交通發展史裡經營運輸帝國。Steam 頁面列出的規模延續這種「堆內容」的續作邏輯：275 種以上真實運具，從馬車一路到高速列車，四大氣候區與隨機生成地圖。

但據 Manu Oehler 在觸樂專訪中表示，團隊的主要目標之一是「把遊戲做得更偏 Tycoon」，希望每個功能裡都有更多可玩性；至於哪些東西要改，他們的判準是：能靠更新修正的就在現有遊戲裡修，「已經沒辦法只靠更新解決的」才留到下一代重新設計。換句話說，這一代動刀的都是傷筋動骨的系統，而最關鍵的一刀落在貨物流。

## 「一開始就知道終點」的貨物

{% gameImage "screenshot_03.jpg", "沙漠地形中的煉油廠與油罐車隊", 1920, 1080, "沙漠地圖上的煉油廠與油罐車隊：原料進廠、成品外運的產業鏈，正是《狂熱運輸3》讓玩家自行決定貨物中途去向所要服務的典型場景。" %}

據 Manu Oehler 在觸樂專訪中表示，在《狂熱運輸2》裡，一件貨物在遊戲開始的那一刻就已經知道自己要去哪裡。他直言這有點奇怪，因為多數玩家的想法是「我先把東西運起來，然後再決定它應該去哪裡」。這種怪感覺來自一個具體場景：當你建立一條還沒有確定終點的線路時，貨物可能根本不會移動，因為它沒有最終目的地。用他的話說，玩家會覺得「它應該先動起來才對」。

《狂熱運輸3》的做法，是把目的地從「開局寫死」改成「玩家隨時決定」：貨物可以先運到一個倉庫暫存，之後再繼續運輸。從設計角度看，這是把貨物從一張開局就填好的訂單，變成一連串中途決策——前者的樂趣集中在開局，後者的樂趣分佈在整局。官方這支〈Transport Fever 3 - Tycoon Gameplay Overview〉以大亨玩法為主題，正對應這波經營化改造的方向：

## 先運到哪裡，玩家說了算

{% gameImage "screenshot_05.jpg", "海上轉運平臺以吊臂卸下駁船上的散裝貨", 1920, 1080, "海上轉運平臺把散裝貨從駁船卸下、旁邊還靠著載運木箱的貨船——貨物在中途節點換手的畫面，對應新貨物流裡「先運到樞紐再分送」的玩法核心。" %}

暫存倉庫聽起來只是小功能，但「先運到哪裡由玩家決定」等於允許玩家自己建立運輸樞紐：把貨物集中到一個地方，再按需求分送到不同方向。Steam 的介紹也把經營壓力寫得直白——每一趟運輸都能獲利，但每輛火車、卡車、飛機與船隻都會增加成本，玩家必須在維護成本與運輸效率之間取得平衡，並用資料圖層與視覺化顯示找出交通熱點與配送問題。當「運到一半」成為合法狀態，玩家的日常工作就從「畫完線路等報表」變成「不斷決定下一站」，這正是 Tycoon 化在機制層的落點。

## 選地圖就是選玩法

{% gameImage "screenshot_01.jpg", "亞寒帶針葉林與湖泊間的村落與直升機", 1920, 1080, "針葉林、湖泊把可用走廊切得零碎，村落與直升機夾在其中——這正是專訪所說「湖泊與森林逼玩家想辦法找路線」的那類地圖。" %}

據 Manu Oehler 受訪時表示，他最希望玩家第一次玩就注意到的變化是地圖：溫帶地圖若是高山多，修鐵路會非常困難；北歐地圖湖泊與森林多，得想辦法找到合適的路線；沙漠地圖視覺效果更好、山丘更深；熱帶地圖則更偏向船運。也就是說，選地圖就等於選一套玩法，而不是選一張背景。Steam 頁面列出的四大氣候區中包含全新的亞寒帶區域，隨機生成的地圖搭配不同生態群落，也會帶來不同的遊玩挑戰。對一個以「修路」為核心的系列來說，這是把重玩價值綁在地形決策上，而不只是綁在車輛清單上。

## 聲望系統：不禁止你拉直線，但讓直線有代價

{% gameImage "screenshot_07.jpg", "雙線電氣化鐵路切過田野並設有隔音牆", 1920, 1080, "鐵路以路塹穿過農田、沿線設隔音牆與陸橋——基礎設施配合地形與聚落配置的畫面，正是聲望系統想鼓勵的建設方式。" %}

同一段訪談裡還有一個容易被忽略的訊號：團隊正在強化聲望系統，希望玩家建設基礎設施時「不只是把線路筆直地穿過整個地圖」，而是能考慮地形與周圍環境。我們認為，聲望是典型的柔性反最佳化設計——它不禁止玩家拉直線，但把「對環境的尊重」寫進報酬結構，讓最短路徑不再是唯一解。Steam 的功能列表也補上配套：進階交通模擬包含車道調控與超車等擬真行為，資料圖層能顯示噪音或汙染的所在；一條硬穿城鎮的線路，在系統裡是看得見、算得到的。從設計角度看，這與貨物流重做其實是同一個方向：前者讓玩家的決定留在營運階段，後者讓玩家的決定要對世界負責。

## 取捨：自由度的帳單誰來買

把決策搬到全程，代價是複雜度。貨物可以隨意暫存、轉運，代表新手第一次開啟遊戲要面對的不再是一條線路的對錯，而是一整張物流網的取捨。對只想放空鋪軌道的玩家來說，這可能是一種負擔。反過來看，Steam 頁面上的設計已經預留退路：大亨模式的難度可高度自由調整，沙盒模式甚至能徹底關閉經濟系統，專心建設城市、車站與場景。

另一個可能的反讀是：太自由的貨物流會讓「最佳化」失去明確的對錯標準。對此，專訪裡的城鎮需求系統像是解方——城鎮各有不同的需求要滿足，據 Manu Oehler 在現場演示時的說法，一座海濱城市的商業區發展緩慢，是因為「我們沒有運送足夠的魚」；把視角拉近到單一建築，還能看到它需要多少貨物，「顏色越深，需要的東西越多」。自由決定貨物去向，但世界會用需求告訴你後果：決策有了回饋，自由才不會變成茫然。

## 結論：把決策搬回營運階段

回到開頭的問題：《狂熱運輸3》的設計取捨背後，究竟在解決什麼問題？我們的答案是——它在解決「玩家的決策被壓縮在開局」這個結構性問題。貨物流重做讓運輸從一張開局寫死的訂單，變成全程可介入的過程；地圖差異化讓每次開局的地形決策都不一樣；聲望系統則讓營運中的選擇要對環境負責。三者的共同點，是重新分配「什麼時候做決定」。做了 13 年運輸遊戲之後，Urban Games 加的不是內容，而是決策的時間分佈。對玩家來說，這一代的成敗不再只取決於開局那張圖畫得好不好，而在於中途每一次「下一站去哪裡」的判斷——這也許就是運輸模擬遊戲走到第 13 年，還能讓人重新上手的理由。
