# 充電器大小的 Switch 2 底座？Genki Covert Dock 3 想把「接電視」變成口袋裡的事

帶著 Switch 或 Switch 2 出門，最掃興的一刻大概就是：飯店或朋友家明明有臺大電視，但你手上只有掌機模式，想接上去才發現沒帶底座、沒帶 HDMI 線，原廠底座的體積又實在不像旅行用品。Genki 的 Covert Dock 3 就是衝著這個痛點來的：官方宣稱它把一臺完整的 USB-C Hub、4K HDMI 輸出和 65W PD 充電，塞進一個充電器大小的機身裡。

## 這是什麼？

Covert Dock 3 是 Genki 推出的隨身底座／充電器二合一週邊，官方產品頁直接把它定位成「可以放進口袋的 Nintendo Switch 2 隨身底座」。它長得就像一顆大一點的旅行充電頭：一端是可收折的牆插插頭，另一端一次給你三個埠——官方規格寫著一個 USB-C（支援 PD 充電）、一個 HDMI 輸出、一個 USB-A。

也就是說，它同時是充電器、也是影像輸出裝置。官方的說法是「不用帶笨重的底座、不用多帶線，插上就玩」。

## 為什麼玩家會在意？

它的吸引力不在引數本身，而在「出門在外的接電視成本」被大幅降低。傳統的 Switch 底座是桌上型思維：一整塊機座、固定線材、佔空間；Covert Dock 3 則把底座的功能壓縮到接近一顆充電器的形態，插牆上就能把畫面送到電視，順便幫主機充電。對常帶著掌機旅行、去朋友家打 Game、或在飯店想把遊戲接到電視的人來說，這正好回答了一個很實際的問題：「我可以只帶一顆充電器出門嗎？」

另一個值得注意的點是它的定位不只服務 Switch。官方頁面把相容性寫得很明確，這點後面會再談。

## 它怎麼運作？關鍵概念只有一個

概念很簡單：把「電源」和「影像」兩件事合流到同一顆裝置上。你把 Covert Dock 3 插上牆插，USB-C 接上主機，HDMI 接上電視——主機同時吃到充電、畫面同時送出去。官方宣稱它支援 4K HDMI 輸出與 65W PD 充電，並內建 USB-C Hub 功能，也就是說除了接電視，還能透過 USB-A 接其他周邊。

官方的產品情境圖就是這個用法：手持主機放在桌上，透過一顆小裝置連到大螢幕，旁邊還能接無線手把的接收器之類的東西，整套裝備的體積遠小於傳統底座。

## 哪些是已查證、哪些只是官方說法？

先講最重要的：ON9 並沒有實測過這臺機器，以下規格與使用情境全部來自 Genki 官方產品頁的宣稱，不應該當成我們的實測結論。

**屬於官方宣稱的部分：** 4K HDMI 輸出、65W PD 充電、USB-C Hub 機身、充電器大小可放口袋、插上就玩——這些都寫在官方產品頁上，屬廠商標示，實際表現（例如 4K 輸出的重新整理率、長時間供電的溫度）官方頁面並未進一步說明。

**查證得到的部分：** 官方產品頁目前標示「Covert Dock 3 in stock.」，並且有下單入口，這一點是確定的。相容性方面，官方頁面明確寫著「Compatible with Switch, Switch 2, Steam Deck, and USB-C laptops.」——亦即官方宣告相容 Nintendo Switch、Switch 2、Steam Deck 以及 USB-C 筆電，這邊我們只照官方說法報導，不自行擴大。
