# 哪款遊戲好玩到讓你想「刪掉記憶」重玩一遍？

假如人生給你一次機會，可以把一款遊戲的劇情、角色與結局全部忘得一乾二淨，然後從頭再體驗一次——你會選哪一款？

這個問題在腦子裡轉一轉就會發現不好答。要捨得動用「失憶」這種一輩子大概只有一次的資源，那款遊戲得好玩到一個很特別的程度：不是「內容很多」或「評價很高」，而是「第一次知道的時候」太震撼，震撼到之後每次重開，都覺得自己永遠少了一塊東西。

## 「想刪掉記憶」其實是在懷念第一次

不少玩家可能都有過這種感覺：某個劇情轉折被揭曉的瞬間，整個人愣在螢幕前面，之後不管重玩幾次、走別的路線，都複製不了那個「完全不知道接下來會發生什麼」的自己。如果你曾經在某個轉折前被遊戲狠狠騙過一次，大概就懂那種「好想再被騙一次」的心情。

而且想重來的往往不一定是轉折本身。有時候是在意某個角色的第一次出場、某段配樂第一次響起的時機、某個選擇第一次按下時的猶豫。這些東西都只賣一次，之後的多周目再精采，都是「知道之後的精采」，跟初見是兩種不同的體驗。刪掉記憶這個念頭，說到底就是想把「不知道的自己」找回來。

## 完美傑作，還是滿是缺點的初見？

有意思的是，很多人想失憶重玩的對象，未必是心目中最完美的那款遊戲。UDN 遊戲角落的作者希洛在十週年專題裡被問到這題時說，如果早五年回答，他可能會選《巫師 3：狂獵》或《十三機兵防衛圈》，但現在的答案是台灣出品的武俠獨立遊戲《活俠傳》——同時他也坦白，這款遊戲的戰鬥系統並不出色，2024 年推出時又因為發行商與開發團隊的內部問題而並不完整，實質上只是半成品，被不少人詬病。

一個「戰鬥不出色、發售時還像半成品」的遊戲，卻站在「想失憶重玩」的第一名——這件事本身就很好聊。它大概說明了玩家真正在乎的是什麼：是那段被故事帶著走的時間，而不是系統打磨或完成度評分。缺點記得清清楚楚，還是想從頭再來一次，這種矛盾大概就是「初見無價」最誠實的證據。

## 《活俠傳》：唐門雜魚的江湖，初見才值錢

回到這款遊戲本身。依官方商店的描述，《活俠傳》是一款 PC 單機角色扮演遊戲，玩家扮演的是一名資質凡庸、不受人待見的唐門雜魚「趙活」——沒有主角光環，人生難度 EX-HARD。江湖動盪、唐門式微，仇家前仆後繼打上門來，身為一個嘍囉，要獨善其身還是為門派存亡拚上一己之力，都是玩家自己的選擇。

官方資料裡特別強調兩套系統：一是「天命系統」，玩家有時能做選擇，有時只能被命運玩弄，劇情展開分秒失控；二是人格特質參數會隨著決策與際遇變動，連帶影響人際關係、劇情走向與決鬥策略。再加上門派養成（煉丹房鑽研毒術、鍛冶場鍛造暗器、打雜賺師長好感）與隨機事件，一個「雜魚能不能逆天改命」的故事就此展開。

## 一週目的悔恨，多周目的逆天改命

這種遊戲結構，恰好就是「想刪記憶」情緒的溫床。希洛在文中描述，《活俠傳》龐大的劇情分支裡，玩家做出的種種選擇可能要到很久之後才迎來意想不到的結果；不同路線裡，角色之間的關係與命運可能完全改變。就連同樣的劇情走向，也會因好感度與主角個性衍生出細微的對話變化。他對這段體驗的總結是：「一週目的悔恨，多周目的逆天改命」，從唐門雜魚走到武林傳奇的過程令人回味無窮。

{% gameImage "s1859910_screenshot_02.jpg", "《活俠傳》夜間劇情對話，點蒼明珠葉雲裳把一條手帕送給玩家，旁邊的少女緊張冒汗", 1920, 1080, "夜裡一段手帕推來讓去的小對話——角色關係就是在這種小事裡慢慢長出來的，錯過了才知道在意。" %}

「悔恨」兩個字很關鍵。第一次玩的時候不知道哪個選項重要、不知道這個人以後會站在哪一邊，於是難免留下一些說不出的遺憾。這些遺憾不會因為關掉遊戲就消失，它們會一直卡在那裡，直到你真的重開一輪，才有機會把它們一個個補回去。想刪掉記憶、重頭再來，某種程度上就是想把「彌補遺憾的機會」拿回來。

## 但「重玩一次」其實有好幾種意思

圍繞這個問題，至少可以看到幾種不同的立場。

第一種是「被劇情打中」派：想刪的記憶是轉折與真相，最羨慕的是那些一開局就被蒙在鼓裡、最後一口氣翻盤的體驗。選這種答案的人，名單上多半是敘事密度高、伏筆埋得深的作品。

第二種是「被陪伴感打中」派：在乎的不是轉折，而是那段時間裡跟角色相處的感覺。對他們來說，失憶重玩是想再認識一次某個人，而不是再被騙一次。

第三種正好相反——不刪。理由很實際：《活俠傳》這種多周目遊戲的樂趣，某種程度上正是建立在「你還記得一週目」之上。天命可以逆，但前提是你知道哪裡需要逆；把記憶刪掉，悔恨是沒了，逆天改命的爽快也跟著一起沒了。這派人想保留的，與其說是劇情，不如說是自己跟那段劇情的關係——包括那些不太好看的遺憾。

還有一種很少被提起：想刪的其實不是劇情，而是「還不會玩」的自己。對系統一頭霧水、亂點一通、什麼都新鮮的探索感，一旦學會最優解就回不去了。這種失憶需求通常發生在系統複雜、解法很多的遊戲身上，跟劇情好不好反而沒什麼關係。

## 我們覺得，這題問的是「你懷念哪一種不知道」

我們覺得，「想刪掉記憶重玩」從來不是對遊戲品質的評分，而是一種很私人的心情測驗。會讓人想動用失憶的，通常不是最完美的作品，而是那個「第一次的自己」被深深打動的時刻。《活俠傳》之所以常常出現在這種討論裡，或許正是因為它把「不知道」做成了遊戲的核心：天命不可測、選擇的後果延遲很久才爆發、同一段劇情會因為你這個人的養成路線長出不同樣貌——初見的價值被系統撐到最大，難怪玩完的人會想回到原點。

反過來說，如果你現在就能毫不猶豫地說出一款遊戲的名字，那答案多半不需要多想——那款遊戲早就替你回答過這個問題了。

所以，換你了：哪款遊戲，好玩到讓你想刪掉記憶、從頭再玩一遍？
