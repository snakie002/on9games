## 幻想放置遠征隊

《幻想放置遠征隊》是一款在螢幕底部執行的 JRPG 畫素風放置自動戰鬥遊戲，旅團會自動戰鬥並成長。官方資料標明遊戲共有 7 大主職業、21 個子職業、合計 91 個職業，職業採五階結構，每位決鬥者都有獨特技能與動畫。職業多、任務條件又改過好幾次，玩家最常卡住的就是三件事：職業解鎖條件看不懂、主線任務推不動、轉了高階職業就回不去。這篇整理職業解鎖的追蹤方式、職業徽章的消耗邏輯、v1.0.6 起的降級轉職改動，以及主線任務與附魔、商店的最新調整。

### 職業解鎖的基本流程與追蹤方式

解鎖一個進階職業需要三件事：先把 Class Hall 升到該職業要求的等級，完成它附帶的兩項解鎖任務，再花費一枚對應階級的職業徽章，最後在 Class Hall 的 Class 分頁按下解鎖。解鎖成功後，酒館就會開始出現該職業的招募人選，你可以把現有決鬥者轉成這個職業。

追蹤條件時，一律以遊戲內 Class Hall 的職業頁面顯示為準。官方從 v1.0.3 到 v1.0.6 多次調低並更新任務需求，外部整理的數字只能當規劃參考，別把舊數字當成不變的目標線——這正是解鎖卡關最常見的原因：照著舊攻略農了半天，其實條件早就被下修過。

### 職業徽章與解鎖卡關檢查清單

職業徽章是解鎖的必要消耗品，每解鎖一個職業要花費一枚對應階級的徽章。官方在首發掛機活動的獎勵清單中就包含職業徽章，其他取得途徑以遊戲內顯示為準。

如果你卡在解鎖，照順序檢查三件事：

1. Class Hall 等級是否達到該職業要求。
2. 兩項解鎖任務是否都已完成。
3. 手上有沒有對應階級的職業徽章。

缺哪項就補哪項。另外記得先更新到最新版本：v1.0.3 降低了職業解鎖需求，v1.0.5 調整了部分角色的解鎖任務需求，v1.0.6 又把職業解鎖任務整體調得更容易完成。舊版本卡住的任務，更新後回頭看通常已經寬鬆很多。

### 切回低階職業：v1.0.6 起降級不再受限

重點先講：v1.0.6 已正式移除職業降級限制，現在可以自由切換回低階職業。舊攻略寫的轉了高階就回不去、不能降級等說法已經過時，不用因為怕轉錯而遲遲不敢轉職。

另一個相關好訊息是 v1.0.3 修正了升級後的酒館無法招募低階角色的問題，所以想回頭找低階職業的招募人選，不會再被酒館等級卡住。

### 主線卡關：任務與關卡條件被連續下修

主線推不動時，先確認遊戲版本，因為官方連續多個版本都在放寬條件：

- v1.0.3：最佳化任務節奏，調低部分前中期關卡難度，並降低職業解鎖需求。
- v1.0.5：調整部分角色的解鎖任務需求。
- v1.0.6：主線任務整體大幅放寬，完成當前任務後，更新後的新任務會套用到後續任務，也就是說舊存檔不用重開就能吃到新難度。
- v1.0.7：修正 Region 12（第 12 區域）怪物防禦數值異常的問題。如果你在第 12 區域莫名打不動或被秒殺，更新到 v1.0.7 之後再挑戰。

簡單說，卡關時與其硬農，不如先更新再看任務面板——官方的 P0 優先專案就是防止主線與職業解鎖任務把人卡住。

### 附魔與商店：v1.0.7 的裝備與重新整理調整

裝備與資源跟不上時，v1.0.7 的改動值得認識：

- 商店手動重新整理（Shop Refresh）：重新整理費用每兩小時重置一次，起始費用 10K 金幣，之後每次重新整理增加 10K。想大量補資源就等費用重置再刷。
- 裝備詞綴公式最佳化：官方對各式裝備詞綴做了小幅調整與補償，之前配裝的結論可能要重新算一次。
- Auto-Equip 排序最佳化：自動裝備現在會按角色適用的詞綴合理排序裝備，懶得逐件比較可以先用它打底再手動微調。
- 修正附魔介面可能出現重複附魔的問題，附魔時比較不會浪費資源在同一條詞綴上。
