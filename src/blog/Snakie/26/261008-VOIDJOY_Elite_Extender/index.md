# 不換手把也能升級？VOIDJOY Elite Extender 想把 Switch Pro Controller 變成精英手把

## 這是什麼東西

VOIDJOY Elite Extender 是一個裝在任天堂 Switch Pro Controller「外面」的擴充模組。它不是一顆新接手把，也不是保護殼，而是夾裝在原廠 Pro Controller 背部與上方的附加裝置。官方產品頁標榜，加裝之後原本的 Pro Controller 會多出 2 顆背鍵（P1/P2）、2 顆額外肩鍵（LT/RT）、一鍵 Fn 快捷鍵、42 步宏（macro）、Turbo 連發與按鍵重對映等功能；同一個模組還標示內建光學類比扳機與額外電池。概念很直接：手把本體不換，用一個模組把它「升級」成可以自訂的高階版本。

## 為什麼玩家會在意

Switch Pro Controller 多年來一直有個老問題：手感與續航不錯，但功能性停在原廠設定——沒有背鍵、扳機就是一般數位按鍵、按鍵配置也不能改。想玩需要多指操作的射擊、賽車或動作遊戲，手指就那麼幾隻；想把常用操作搬到背鍵，只能整顆換成第三方「精英手把」。VOIDJOY Elite Extender 走的是另一條路：你已經花錢買過的原廠手把繼續用，缺什麼就外掛補什麼。官方列出的補法包括背鍵與肩鍵共 4 顆額外按鍵、按鍵重對映，以及官方宣稱的 1280 段光學類比扳機——如果真的做到，賽車遊戲的油門與煞車就從「有按／沒按」變成可以漸進控制。

## 它怎麼運作

核心概念是「外掛硬體＋App 設定」。模組夾在 Pro Controller 上，把玩家的按壓透過自己的電路轉接出去，因此才能加上原本不存在的 P1/P2、LT/RT。設定層面，官方表示透過 KeyLinker App 可以調整按鍵對映、燈光、震動、搖桿死區校正、扳機反應、Turbo 與宏；搖桿部分標榜可以自訂死區，過濾輕微偏移的訊號。官方規格寫著扳機採 1280 段光學類比感應；電力方面標示模組自帶 1800mAh，與 Pro Controller 本身的 1300mAh 並存，並有 4 段電量指示。還有一個少見的功能：官方宣稱支援 Android 觸控對映，可以把控制器輸入對應到螢幕上的虛擬按鍵，讓只有觸控操作的手遊也能用手把玩。

## 哪些是官方說法、哪些已經查證

要先說清楚：以上所有功能與數字——4 顆額外按鍵、42 步宏、1280 段光學扳機、1800mAh、14 種功能鍵可對映——全部來自官方商品頁與官方商店資料，屬於廠商標示與官方宣稱，目前沒有獨立第三方實測可以交叉驗證，本文也沒有實測這項產品。能確認的是比較基本的事：這項產品確實存在於 VoidJoy／JSAUX 的官方商店，有明確的商品頁、產品圖與商品編號，官方頁面並標示現貨發售中。多平臺支援（官方列出 PC、iPhone、iPad、Android、智慧電視、Raspberry Pi 等）與「用 Switch 1 的 Pro Controller 喚醒 Switch 2」同樣是官方說法，實機相容狀況仍待驗證。

## 適合誰

最直接的物件是手上已有 Switch Pro Controller、又想要背鍵與自訂配置的玩家：與其另買一顆高階手把，用外掛模組補上 4 顆鍵與宏功能，出發點是省錢也省習慣成本。第二類是賽車遊戲玩家——如果 1280 段光學類比扳機如官方所說，油門與煞車的細膩度會比原本的數位扳機更有發揮空間。第三類是跨平臺玩家：官方宣稱一顆 Pro Controller 可以在 PC、手機、平板、智慧電視等裝置間切換，還能處理純觸控的 Android 遊戲。不過這些都建立在官方說法之上，值不值得入手，還是要看之後有沒有人實測。

## 還沒確認的事與風險

目前沒確認的事不少。第一，夾裝式設計會不會影響握感、重量與長時間使用的舒適度，官方圖看不出答案。第二，1280 段光學扳機的實際精度、延遲表現與耐用度，都只有官方規格，沒有實測資料。第三，42 步宏與 Turbo 連發在部分遊戲的線上模式可能涉及使用規範問題，官方頁面沒有提供這方面的說明。第四，宏與對映的設定門檻、KeyLinker App 的實際體驗，以及韌體更新支援，都沒有第三方資訊。最後是購買層面：官方沒有說明寄送地區與保固細節，海外買家的實際負擔仍屬未知。對這類「把手把改成精英版」的外掛有興趣的話，建議先當作一個值得觀察的新品，等更多實測出現再決定。
