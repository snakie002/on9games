# 不畫黃漆的曼哈頓：《Control Resonant》的引導取捨，在解決什麼問題？

「黃漆」大概是近十年最成功的關卡設計發明，也是被玩家罵得最兇的那一個。可攀爬的岩壁、梯子、缺口，刷上一層顯眼的黃色，誰都知道該往哪走；但批評者也從沒停過：這樣一來，探索不就變成跟著箭頭走？多數開發者在「好找路」和「別被罵」之間折衷，而《Control Resonant》的團隊選了更極端的一條路——在一座「上」與「下」都失去定義的曼哈頓裡，他們乾脆不畫黃漆。

這不是美學潔癖。據 Game Developer 報導，遊戲總監 Mikael Kasurinen 在 Dropped Frames 節目談到這個決定（經 Kotaku 轉述）時，自己承認這種設計有讓遊戲變得「難以親近（impenetrable）」的風險，但他強調不依賴黃色標示是「有意識的選擇（a conscious choice）」。一個明知會抬高門檻的決定，背後要解決的到底是什麼問題？答案比「玩家會不會迷路」深一層。

## 從最古老的房子，到沒有上下的曼哈頓

先交代背景。據 Game Developer 報導，《Control Resonant》推出後在玩家與評論之間獲得不少好評；Remedy 這次把場景從系列熟悉的室內空間「最古老的房子」（The Oldest House）內部，擴張到受「樣板」（Pattern）扭曲的紐約曼哈頓街頭。報導對這個世界的形容很關鍵：這裡的「上」和「下」不再有固定的定義。玩家要在開放的曼哈頓裡靠奔跑、飛行與切換重力，抵達被「正交調整」過的區域。

也就是說，本作的探索不是「在一張大地圖上找路」，而是「在一個方向本身會變動的空間裡找路」。這正是引導設計最怕遇到的狀況。

## 路標先失效：正交空間裡「往哪走」的難題

黃漆之所以有效，靠的是一個隱含前提：世界有穩定的垂直方向。畫在岩壁上的記號永遠指向「上面」，玩家的世界觀跟設計師的世界觀是同一個。可是當整棟樓可以被轉九十度貼上另一棟樓，一條水平的箭頭就失去意義——這面牆是可攀爬的路線，還是別人的天花板？「往上走」在這裡甚至不是一句完整的指示。

我們認為，這正是「黃漆問題」在本作被放大的原因：當座標系本身會旋轉，外加路標必須先回答「以誰的上下為準」，標示的成本不再是一桶油漆，而是整套座標系統。另一個選擇是把標示做到無所不在——每面牆、每個角度都給提示——但那樣的世界會變成一張貼滿標籤的說明書。Kasurinen 團隊面對的其實不是「要不要引導」，而是「用什麼當引導」。

## 「就不再是一個決定」：要還給玩家的東西

據 Game Developer 報導，Kasurinen 把這個選擇的核心錨定在一個玩家感受上：他希望玩家覺得「是自己找出該怎麼探索曼哈頓的」。他認為過度的標示——黃漆或其他記號——會讓玩家覺得「遊戲已經替他們決定了路線」；用他本人的話說，當引導讓人感覺是「去這裡」，那「就不再是一個決定了」（“If it feels like it's like 'go here,' it's not anymore a decision”，引述片段出自 Game Developer 報導）。

{% gameImage "official_05.jpg", "角色在傾斜的視角中懸浮下墜，遠處爆發的能量與霧氣打散方向感", 1920, 1080, "角色在傾斜視角中懸浮下墜、雙腳離地，能量爆發與霧氣把方向感完全打散——移動本身就成了玩家要做的第一個決定。" %}

從設計角度看，這句話點出了一個常被忽略的取捨：標示降低的是「抵達的摩擦」，但同時也降低了「發現的重量」。在一個上下顛倒的曼哈頓裡，玩家自己想通「這面天花板其實是路」的那一秒，正是這套重力系統最有價值的回饋；而黃漆會把那一秒提前沒收。換句話說，Kasurinen 在保護的不是畫面乾淨，而是「發現」這個動作本身的含金量。

## 代價：門檻、挫折感，與反面讀法

但這個選擇不是免費的，Kasurinen 自己點出了最大的風險：遊戲可能變得「難以親近」。並不是每個玩家都想在下班後解一道空間謎題才看得到下一段劇情；對只想推進故事的人來說，被一個沒有標示的正交空間卡住，感受不會是「我真聰明」，而是「這遊戲到底要我去哪」。探索感的歸屬拿回來了，代價是挫折門檻一起被抬高。

{% gameImage "official_04.jpg", "多層混凝土室內場景中角色與紅色能量敵人交戰，畫面沒有任何路徑標示介面", 1920, 1080, "官方截圖中的多層混凝土室內場景與戰鬥畫面裡看不到任何路徑標示——連混亂的室內戰鬥，讀空間也得靠玩家自己來。" %}

還有一個更嚴苛的反面讀法：不畫黃漆，不等於做好引導。真正撐起這套設計的，是環境本身有沒有用形狀、光線與構圖把「可能的路」暗示到位——如果場景的可讀性沒跟上，玩家感受到的就不是「我自己發現的」，而是「我根本不知道能這樣走」。這兩者的界線非常細。我們認為這才是本作真正的設計賭注：把引導從顯性的記號轉移到隱性的空間語言上，成敗取決於後者的功課做得多深，而這一點，光看官方畫面無法下定論，要看玩家實際玩過之後的反應。

## 結論：它在解決的不是迷路，是「成就感歸誰」

回到開頭的問題：這個取捨背後究竟在解決什麼？不是「玩家找不到路」——對一個上下都會翻轉的世界來說，黃漆根本是無效標示；Kasurinen 真正在處理的，是探索的成就感算誰的。過度標示等於開發者替玩家承擔了找路的責任，順手把發現感收走；不畫黃漆，則是把責任連同風險一起還給玩家，用「可能難以親近」換「這條路是我自己走出來的」。

對玩家來說，這決定了你在《Control Resonant》裡得到的是「照著指示抵達」還是「自己想通的那一刻」；對設計者來說，這是一記提醒：引導的極限不只是讓玩家抵達終點，而是讓他相信終點是自己找到的。至於這場賭注最後賠率如何，得由每一雙在倒懸曼哈頓裡迷路過、又自己找回方向的玩家來回答。
