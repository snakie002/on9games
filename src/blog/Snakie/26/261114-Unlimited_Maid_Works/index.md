# 《Unlimited Maid Works》正式公開登 Steam：Roguelike 女僕模擬顧程序生成住戶，做不好會被解僱

《Unlimited Maid Works》是一款以女僕為主角的 Roguelike 沙盒遊戲，玩家要管理一整戶人家，服務每位個性獨特的主人。本作由 Clumsy Tails LLC 開發與發行，目前僅支援 Windows 平臺，支援單人、多人與線上合作遊玩。Steam 商店頁面目前標示「即將推出」，確切發售日期尚未公佈。官方網站目前則標示遊戲預定 2027 年春季推出。光看名字與標題圖的字型設計就知道，官方根本是在向《Fate》系列的「Unlimited Blade Works」致敬。

## 遊戲介紹

遊戲中的住戶與主人採程序生成，每局合約都要重新適應不同的房子與主人需求。官方網站以「Serve. Clean. Survive the contract.」形容這份工作，並提到玩家可以接手其他被解僱女僕留下的合約。換句話說，女僕這份工隨時會丟，前手搞砸的爛攤子還得接手收拾。

{% gameImage "screenshot_01.jpg", "女僕在房間中清潔桌子", 1920, 1080, "官方 Steam 遊戲截圖（開發中畫面）：昏暗的哥德風房間內，女僕正在擦拭木桌，畫面左上是任務清單，右側為道具欄，底部是狀態列，桌旁顯示清潔後的分數。" %}

打掃範圍涵蓋地板與傢俱，連屋內的盆栽和寵物都要顧好，才能維持主人的滿意生活。清潔與維持家中的整潔，是每一局最基礎、也最花時間的日常工作。食材從栽種到上桌一手包辦，玩家要取得優質農產並烹調出豐盛菜餚。健康的飲食同樣是主人生活的重要一環。

{% gameImage "screenshot_02.jpg", "女僕在廚房烹調料理", 1920, 1080, "官方 Steam 遊戲截圖（開發中畫面）：廚房場景中女僕站在爐灶旁，畫面顯示「Fresh Meat」料理選項與任務目標，左側是當回合的任務清單，底部是狀態列。" %}

室內設計也是女僕的工作，添購傢俱除了改善主人的生活環境，各款傢俱組合還附帶不同的實用效果。與此同時，隨著工作表現越好，女僕本身也會變得越強。「公司」提供龐大的服裝目錄，玩家可以自由搭配與染色；部分服裝不只好看，還能帶來戰術上的優勢。（「打掃煮飯種菜換傢俱，仲要保住份工——呢份女僕真係唔易做。」）

{% gameImage "screenshot_03.jpg", "佈置完成的主人房間", 1920, 1080, "官方 Steam 遊戲截圖（開發中畫面）：佈置好的哥德風臥室，鋪上粉紅格子床單的床鋪旁有多名角色與白色小生物，右側站著一名高瘦的蒼白角色，窗外是下雨的庭院。" %}

遊戲設有全球排行榜，玩家也可以加入「女僕聯盟」（Maid Union），帶領組織在排名中爭取榮耀。
