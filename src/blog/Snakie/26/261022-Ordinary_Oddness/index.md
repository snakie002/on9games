# 《Ordinary Oddness》正式公開：在雲上都市開一間偵探事務所，專門接「不太對勁」的委託

又有一款開放世界 RPG 正式公開。由 COSMICPUP STUDIO 開發兼發行的《Ordinary Oddness》，官方形容它是一款「Nothing-Stays-Oddinary」的開放世界 RPG：自「Albinox Judgment」事件之後，人類與名為 Mythoids 的怪奇生物在懸浮於雲海之上的都市 Elysian Skies 共存，走在同一條街上、遵守同一套日常規則。遊戲已在 Steam 開放商店頁面，發售日則尚未公佈。

玩家將扮演由 Mythoids Investigation Agency 認證的諮詢調查員，在 Breezeway Lane 開設自己的事務所，接受來自人類與 Mythoids 的各式委託。官方在商店頁寫得相當直白：規則會失效、日常會扭曲、真相不一定撫慰人心——但這座都市永遠歡迎你回來，怪咖。

## 遊戲簡介

Elysian Skies 是一座懸浮在雲海之上的城市。官方的公開告示寫道：城市運作正常，Mythoids 是城市的永久居民，和你共享這座城市；城市不提供任何推薦路線，從哪裡開始完全由你決定，「規則即將失效，自行判斷行事」。也就是說，這不是一款照著任務清單跑的開放世界遊戲——官方把「沒有固定路線」直接寫進了世界觀裡。

{% gameImage "screenshot_02.jpg", "雲海之上的 Elysian Skies", 1920, 1080, "官方 Steam 遊戲截圖：黃昏時分漂浮於雲海之上的都市全景，天空呈現碎裂玻璃般的紋路，裂痕透出底層星空；畫面中央是一座由幾何玻璃面板堆疊而成的巨型高塔，部分面板透出粉紫色光；左側是漂浮的主題樂園，有摩天輪與蜿蜒的雲霄飛車軌道，遠處散佈著浮島、熱氣球與飛行載具，畫面中沒有角色與操作介面。" %}

從官方釋出的畫面可以看到，城市裡的日常同樣不太「普通」：城鎮廣場上會出現大型布偶造型的遊行花車、金色鳥籠造型的華麗裝置，街頭有樂團演奏，空中漂浮著魚形的奇妙裝置。人類與 Mythoids 共處在同一個畫面裡，正是這款遊戲想表現的日常風景。

{% gameImage "screenshot_03.jpg", "糖果主題的遊行花車", 1920, 1080, "官方 Steam 遊戲截圖：糖果主題的慶典遊行，中央是一座巨型甜點花車，上部是帶小眼睛與粉色蝴蝶結的白色棉花糖造型圓形結構，金色平臺上站著一位頭部為顯示螢幕、穿粉色服飾的角色，四周圍繞四位銀色女性人形裝置；花車底部是紅色糖漿般的結構，裝飾著巧克力方塊、藍莓與綠葉，上方環繞金色蝴蝶餅狀圓環；背景是開花的櫻花樹、東亞樓閣式建築與現代高樓，彩帶在空中飛揚。" %}

就連慶典本身都帶著怪奇生物的氣息：棉花糖造型的白色生物睜著小眼睛看著人群，頭部是顯示螢幕的角色站在花車上向街道揮手。共存不只是世界觀設定，而是畫面裡隨時都在發生的事。

## 戰鬥與委託調查

官方把戰鬥形容為「城市不提供標準的戰鬥方式」：每一個 Mythoid 都有自己的形態與戰鬥風格，玩家必須視情況調整機制與能力的運用，而且「上一場奏效的打法，下一場未必有用」。換句話說，比起背招式，觀察對手才是這款遊戲的戰鬥核心。

{% gameImage "screenshot_04.jpg", "與 Mythoid 交戰的畫面", 1920, 1080, "官方 Steam 遊戲截圖：昏暗的工業機械場景中發生劇烈爆炸，藍白色閃電般的能量四散，碎片懸浮半空；畫面右下方一名銀白短髮的男性角色背對鏡頭，穿著帶紅色縫線與白色星形符號的黑色外套，右手握著巨大的鐮刀狀武器，前方是爆炸的火光與煙霧，左下可見巨大的金屬齒輪。" %}

委託方面，城市全年無休接受案件，每一件怪奇事件的檔案「都不止一頁」。Mythoids 的起源、共存的開始、城市的過去，全都還在等待解密，真相會隨著調查一層一層揭開。官方也標示遊戲畫面是以 Unreal Engine 5 拍攝，強調霓虹雲海、城市街道等場景都以原始規格呈現，沒有縮水簡化。

## 編輯觀點

開放世界 RPG 市場不缺大作，缺的是把「怪」做成核心的作品。《Ordinary Oddness》選擇讓「規則失效」成為世界觀的一部分，戰鬥不給標準答案、探索不給推薦路線，這條路最終能不能走通，要看成品能不能把「每次都不一樣」做得公平又有趣——但光是設定就已經夠特別：在雲上都市開一間事務所，專門收留這座城市的怪。

「成個城市都係怪咖，你仲走去做調查員？正正因為咁，先至好玩吖嘛。」

值得注意的是，Steam 標示本作是 Free To Play，五種語言全部含完整語音，繁體中文也直接列入其中，野心明顯不限於單一市場。目前商店頁面只標示 Windows 版本，發售日也尚未公佈，有興趣的玩家可以先到 Steam 頁面加願望清單，等官方公佈更多訊息。
