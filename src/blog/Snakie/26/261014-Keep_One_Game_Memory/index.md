# 如果只能留下一段遊戲記憶，你會留下哪一段？

如果有一天，你的遊戲人生只剩下一段記憶——不是一片收藏、不是一個存檔，而是真的留在腦子裡、偶爾會自己浮上來的那「一段」——你會留哪一段？

這個問題沒有標準答案，但有趣的地方在於：多數人其實不用想太久。有人腦中馬上出現的是一個畫面，有人想起的是一個時刻，還有人第一個想到的根本不是遊戲，而是當時坐在旁邊的那個人。

## 為什麼我們留下的永遠只有「一段」

現在的玩家其實什麼都留得住。存檔、成就、截圖資料夾、遊玩時數、直播錄影，就連最後一次登入的時間都查得到。雲端幫你記得每一場戰鬥，社群幫你記得每一個版本改了什麼。可是當有人問你「你還記得什麼」的時候，這些紀錄幾乎都幫不上忙。

浮上來的通常只有一段。

可能是某個後來再也沒回去過的城鎮；可能是某個打到凌晨三點的關卡；可能是某個早已不開機的語音群組。記憶不像存檔那樣照單全收，它有自己的過濾規則。不少玩家可能都有過這種經驗：破關的劇情細節早就忘光了，某個不重要的午後、某段走過很多次的路，卻一直留著，而且說不出為什麼。

## 一款只玩兩三個晚上的遊戲，留下的卻是整片森林

前陣子 Reddit 的 r/patientgamers 上，使用者 /u/plantsandramen 分享了一篇《The Vanishing of Ethan Carter》的遊玩感想。他當時正在等《巫師3》重製版上市，想從遊戲堆裡挑一款夠短的遊戲來填空檔，於是選中了這款大約一到三個遊玩時段就能完成的作品。照他的說法，那是一年當中最適合「初秋」的遊戲。

他在貼文開頭引用了遊戲裡的一句話：「你知道鬼是什麼嗎？他們是悲傷的、被逐出的東西——是沒有家的記憶。」

照他的描述，遊戲的舞臺是一座被湖泊、山脈、水壩與鐵道圍住的森林小鎮，鎮上只剩幾棟空屋、一座水力磨坊和一間教堂，安靜得像是被世界忘記的角落。他說這片森林扛起了他大部分的樂趣：因為他「在松樹間長大」，鳥叫聲一響，就有回到家的感覺。他還特地去查了場景的視覺靈感來源，發現竟是波蘭；他唯一的小抱怨，是遊戲裡聽到的藍松鴉與潛鳥都是北美才有的鳥種，跟預想中的地理搭不上。用他的話說，這是個「小小的挑剔」，完全不影響他對這片風景的喜歡。

值得注意的是，他記住的並不是「我破關了」這種成就感。他留下的是樹、鳥叫聲，和一種置身其中的安穩。一款兩三個晚上就結束的遊戲，最後變成了一段可以隨身帶著走的風景。這大概也是為什麼那句「沒有家的記憶」放在這裡特別貼切——玩完之後，那段風景就只能住在人的腦子裡了。

## 熱血的、安靜的，還有跟「人」有關的

當然，每個人想留的那一段長得很不一樣。

有人要留的是最熱血的瞬間：卡了三天的王終於倒下、逆轉的那一波、全隊同時刷出來的那排驚嘆號。這種記憶的特點是喊得出來，回想的時候拳頭還會跟著握緊。

有人想留的反而是最安靜的瞬間：像上面那片沒有戰鬥也沒有任務的森林，或者某個遊戲裡什麼都不用做的午後。這種記憶沒有臺詞、沒有數字，卻往往最難被取代。

還有一類記憶，其實是「人」的。如果你曾經固定和一群人約時間上線，你大概知道那種感覺：遊戲內容其實早就玩膩了，但語音裡的聲音還在，就值得再開一次。等到群組安靜下來、帳號一個個灰掉之後，你想留的那「一段」，多半就跟某個人有關，而不是跟哪一關有關。

也有人想留的其實是「版本」。遊戲改版了、地圖重畫了、伺服器關了，記憶裡那個世界已經不存在於任何一臺硬碟上。這種記憶最像那句話說的：沒有家的記憶。它沒有地方可以「載入回去」，只能靠人一直想著。

## 我們覺得，記憶挑的其實是「當時的你」

我們想了很久，覺得這道選擇題真正的答案，可能根本不在遊戲身上。同一款遊戲，在不同的人生階段玩下來，會留下完全不同的記憶。能被記住的那一段，多半剛好對上了當時的你：剛好很有空、剛好很累、剛好有人陪，或者剛好需要一個安靜的地方待著。

所以「只能留一段」這個殘忍的限制，與其說是在考驗哪款遊戲比較有份量，不如說是在逼我們承認一件事：我們真正想儲存的，是遊戲替我們標住的某段人生。存檔可以備份，時數可以截圖，成就一排一排列得整整齊齊，但這種東西沒有匯出鍵，也不支援雲端同步。

## 那麼，你會留哪一段？

如果真的只能留一段，你會留最熱血的那個瞬間，還是最安靜的那一個？是某一個人、某一片再也回不去的風景，還是一段連自己都說不清為什麼記到現在的畫面？

說不定你心裡其實早就有答案了，只是很久沒有認真回答過。
